Supabase SQL 01~04 실행 후 사용. config.js에 제공된 공개용 연결 정보가 입력되어 있습니다. GitHub 저장소 루트에 8개 파일을 업로드하고 Vercel에서 Framework Preset Other, 빌드 명령 없음, 출력 디렉터리 기본값으로 배포하세요. 별도 npm 설치 불필요.
교사 페이지에서 방 생성 → 학생 페이지(다른 탭 또는 기기)에서 입장 → 시작 → 답안 제출 → 종료 → 결과 확인 → 방 삭제 순서로 테스트하세요. 교사 인증은 localStorage, 학생 인증은 sessionStorage에 보관합니다. 학생 탭을 닫으면 인증이 사라질 수 있습니다. 기존 교사 방이 삭제된 경우 브라우저 사이트 데이터에서 wai-host를 제거하세요.
동기화는 기존 SQL의 인증 RPC를 2초마다 호출하는 방식이며 Realtime 구독은 사용하지 않습니다. 듣기는 기기 내 Web Speech API에 의존합니다. 30명 동시 접속 및 실제 서버 테스트는 배포 후 필요합니다. 게임 점수는 공식 성취도와 별개입니다. CSV는 학생별 요약입니다. 학생별 세부 유형 분석은 학생 자신의 결과에서 제공됩니다.
